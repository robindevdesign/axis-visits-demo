# Axis Visits — Presentation Demo

This is an isolated presentation copy of Axis Visits. It does not modify the existing `axis-visits-demo` repository or connect to its Supabase workspace.

## Open the demo

https://robindevdesign.github.io/axis-visits-demo/presentation-demo/

The page opens in demo mode automatically. It uses fictional sample visits and stores changes only in the current browser. Each visitor gets an independent demo workspace. No real guest accounts, email invitations, or push notifications are sent.

To run the same build locally, start a static server in this folder and open `http://localhost:8000/?demo=1`.

The demo includes the visit dashboard, role switching, guest questionnaire and travel guide previews, booking categories, hotel export, QR codes, and sample notifications. The travel guide is grouped by day and category and includes a local cover image.
